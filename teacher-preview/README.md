# 國字森林離線試玩

直接雙擊 `hanzi-offline.html`，用 Chrome、Edge 或 Safari 開啟，就能選課、看國字拼注音、手寫國字及重練錯題。這個檔案已包含 84 個國字、168 個詞語和 84 份筆順資料，不必啟動伺服器或連上網路。

這份試玩固定使用老師示範身分，紀錄只存在目前瀏覽器分頁，不會登入學生帳號、送出正式成績或發放卡片。已寫的筆跡與未完成回合可在同一分頁重新整理後接續；關閉分頁不保證保留。老師的班級作業、小考和正式收藏須使用整合後的班級網站。

離線版使用既有棉花兔和暮影小伯爵圖片，保留答對攻擊、答錯受擊與能量變化。為保持檔案精簡，角色動作使用離線動態效果，沒有包入正式站全部動畫素材。手寫題依詞境出題，提示字旁有注音，筆跡在裝置上自動判斷。筆順素材完整授權文字可由檔案頁尾下載。

開發者更新來源後執行：

```powershell
node tools/build-hanzi-preview.mjs
node --test tests/hanzi-ui.test.mjs
```

建置直接讀取目前的 `hanzi.html`、`hanzi.js`、樣式、題庫、手寫元件與評分核心。僅在封裝時替換離線身分、圖片與動畫載入介面；不修改正式來源檔案。CSP 禁止外部連線，內建資料由封裝中的記憶體讀取。

瀏覽器測試以全新 headless Chrome 驗證，不連接使用者已開啟的瀏覽器。涵蓋認讀一回合、正誤角色回饋、錯題精準重練、手寫格、重新整理後筆跡恢復，以及 1024、768、390 像素寬度。驗收圖存於 `docs/hanzi-qa/`，也可用 `HANZI_SCREENSHOT_DIR` 指定位置。另在相鄰的後端測試副本可用時，直接載入未修改的學生頁面，透過記憶體路由和獨立 SQLite 驗證作業、小考、成績及不重複領卡，並檢查正式角色／怪物動畫畫布確實可見。

這些是桌面瀏覽器測試，實體 iPad 的手指／Apple Pencil 操作仍應另行驗收。
