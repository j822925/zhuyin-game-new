## 教學內容與操作

- 康軒一年級上學期，預備課與第1～6課，共84字、168個完整注音詞境。甲乙本只用於教材核對，不作為出題範圍。
- 教師勾選已教課次；自由練習可選其中幾課，作業和小考採建立時的題目快照。目標字限已教課，提示詞可含簡單課外字，例如長短；提示字與歧義提示均有注音。
- 認讀題依詞境選聲符、韻符／結合韻、聲調。無聲符與無韻符都有明確選項，不把未選當空答案。
- 書寫題隱藏目標國字，顯示其注音；白色田字格最大約390 CSS px，隨螢幕縮放。保留真實落筆、移動、抬筆順序，可上一筆、重寫；練習可看筆順，小考不提供示範。
- 完整有效的答案自動判對錯，答對使用既有角色攻擊，答錯受擊。每題只記錄首次提交；小考也有即時戰鬥。空白、中斷、過量筆跡等無效輸入當下要求重寫，不扣分、不進教師等待。
- 完整回合送後端重新判定；畫面成績只讀權威 `run.result`，不以本機顯示冒充已儲存結果。相同請求重送不重複計分。
- 作業支援全班／指定六位學號與回合數，小考有時間範圍及既有卡片選擇。滿分、未看提示、符合原卷獎勵設定即可領卡；每生每考最多一張，收藏與頭像沿用既有功能。
- 錯題依題型與題號合併最近結果，重新答對即移出，歷史成績仍保留。後台可重播原始筆跡、逐筆查看、選用誤判修正。
- 題庫管理支援新學期、課次、國字、例詞、逐字注音、目標位置及驗證後匯入。尚無有效筆順資料的新字可練認讀，書寫標「準備中」，不任意判錯。

## 自動書寫政策

使用 `gradingPolicy: automatic-v1`，練習與小考相同。參考軌跡為83字 AnimCJK 臺灣庫及1字原創「蛙」候選，完整來源和授權在 `licenses/hanzi-*`。筆畫數核對、逆序、逆向與同筆數混淆比對均有測試。

此為可調整的幾何判定，並非經兒童筆跡驗證的準確率保證。模板保留 `practice-only` 來源標記，代表尚未做兒童與實機校準；依教師最新要求，這個標記不再攔住自動評分。`confidence`、字形／筆順診斷與原始筆跡保留，供事後改進。沒有啟用付費OCR、雲端AI或iPad鍵盤轉字。

每字／每筆最多2000點，超限明示重寫而不靜默截斷。傳送時將座標保留六位小數、時間保留毫秒，不改動本機墨跡；最長10題書寫回合已測低於1 MiB，API接收上限為2 MiB。
