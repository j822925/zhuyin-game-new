# 國字森林平板改版

介面版本：hanzi-five-correction-stars-v2。基準前端 16b16d3；後端沿 e810a93e 完整設定與既有 runtime，保留加減玩及其他功能。

- 首頁沿原 world／world-art／character-portrait，使用既有星夜貓頭鷹與「日・月・山」木牌，沒有新增大型圖檔。
- 營地只保留兩種練習、接續進度及必要狀態。課次完全由教師設定；首次開放第 1 課「拍拍手」。
- 老師小考及錯題本整合原學習廣場入口，完成複習或小考可返回原入口。
- 題目置中、敵左我右。1024×768 與 768×1024 瀏覽器驗證輸入及送出可見；這不是實體 iPad／學校 Wi-Fi 驗收。
- 自由練習每回 5 題；錯題本單題複習、已建立作業／小考沿原指定題數及快照。
- 作答前主動看筆順，每題只增加 1 題；同題重看不累加。附加題也遵循此規則。答錯強制示範不加題。
- 新練習答錯必須完成筆順／原老師錄音示範，再正確訂正才能前進；保留首次答案與成績。切到背景、重整、離開營地不能略過尚未完成的示範。
- 新練習首次全部答對，每回原子增加錢包 1 星，無每日上限；看提示本身不扣全對資格，新增題也須答對。重送同回合不重複發星。小考維持原卡片規則，舊回合不補發新獎勵。
- 教師「開放課次」及「學期與生字」提供新增學期、課次、生字及草稿儲存。現有 84 字全部具書寫參考；新字缺筆順參考時會明示書寫待準備，先提供認讀，不捏造書寫判定。

驗證：後端新規則 5 項（含重送競態、訂正、加題、錢包失敗回滾）；既有 API／store／runtime／領卡 37 項；試點授權 8 項；教師 UI 實際 SQLite 編輯新學期／課次／生字；學生真 Chrome 使用記憶體路由及虛構 SQLite，測兩種訂正、重整、失敗重送、連續獎勵及廣場整合。加減玩原小考／錯題本瀏覽器回歸通過。正式版本與線上驗證另見專案交接，不把本機結果當已發布。
