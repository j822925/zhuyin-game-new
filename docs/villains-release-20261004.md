# 36 位可愛反派正式上架

前台版本：`20261004-villains1`。原有 4 位與已確認的 32 位新增反派合計 36 位，正式隨機池、收藏圖鑑及可用夥伴目錄共用相同識別。每回合由後端隨機決定反派，可以重複，孩子不能指定敵人。同一隻累積三次整回合全對並儲存成功才加入收藏；既有收藏及進度保留。

新角色沿用已複核的兩組六姿勢圖集與逐格身體比例，共 384 張姿勢，正式播放器支援出招、護身、受擊恢復、勝利、捧星及敗北。敵方在左向右，我方完整鏡像在右向左，捧星限我方。每組角色固定站位与同一個整體縮放，避免出招、側身及展開翅膀改變角色尺寸；快取以最近六位為限，關閉畫面取消動畫。缺圖保留原肖像作備援。

鏡面光束、單張黑桃牌、筆尖墨滴及箱口金幣沿用已確認效果，投射物從實際發射部位飛向答題介面的對手；特效層不接收點擊。新角色攻擊採 1800 毫秒節奏，受擊時間與出招同步，舊角色節奏維持。朗讀、練習、小考及連線模式共用控制器與目錄。減少動態模式停用位移與投射特效。收藏卡面使用各自圖像、色彩、標記與邊框類型。

後端來源以目前部署 `f161e715-a140-4a95-95ef-3c37f3b479f7` 的保存來源圖為基底，只擴充 `data/monsters.js`、新增造型目錄，更新健康端點的版本與反派數量，以及遇敵函式的版本相容分支。其餘所有來源模組經內容比對確認一致；老師試玩路由、254 件公開資源與兩個班級設定保留。新版本 `bc63db7b-d890-44e4-a830-8d2c16fd35f6`。部署順序為前台先就緒，再切換後端，避免新增遭遇被舊前台當成未知角色。沒有資料表變更或學生資料匯出。

驗證：7 項前台測試通過，涵蓋完整隨機池、所有肖像和圖集、動作時長、舊角色節奏及實際對手位置的投射物。32 位新角色全部用瀏覽器載入 12 姿勢，敵我两側的 4032 個姿勢組合檢查顯示邊界，並比對攻擊／受傷／慶祝的完整鏡像像素、發射點與我方限定第 10 格捧星。正式答題 demo 驗證完整兩回合、答錯／答對、墨滴／金幣、下一題取消特效、收藏 36 位、角色選用、捧星與 390／768／1280 像素排版。

朗讀以攔截 API 的虛構回應驗證新夥伴及反派、辨識錯誤重錄、正確／錯誤反應、未確認入帳不顯示收藏、保存失敗重試、下一題與離開取消動畫、手機排版，以及既有四位反派的星星與鏡像回歸。後端使用純本機虛構資料，在兩個班級逐一測試 36 位，共 288 回合：隨機覆蓋、客戶端無法指定、答錯不計次、三次全對解鎖、重送不重複、全部可儲存為我方角色、班級隔離皆通過；既有朗讀給星、錯題本與權限回歸也通過。未寫入正式學生成績；尚未以實體 iPad 或全班同時連線驗證。

新前台在開始遇敵時宣告目錄版本；後端只依此選用擴充 36 位或舊版 4 位的隨機池，不接受客戶端指定角色。尚未重新整理的旧頁面可完成原有回合；刷新後使用全部 36 位。既有遭遇仍依相同回合識別讀取，不重新抽選。
