# 年度注音闖關

本文件說明 `20261111-retry1` 的操作與整合介面，沿用前版五關、加題及獨立活動模式。網站發布、桌面瀏覽器及學校實體 iPad 的驗收結果，分別記錄於本機專案交接；檔案完成不代表已在線上生效。

## 入口、登入與現場操作

池東探險島一年級首頁保留兩個入口：「闖關預演」及「正式闖關」。尚未登入時顯示登入提示；登入後只查詢這位孩子在兩種模式的開放狀態，不下載全班名單。入口可見不等於取得闖關權限，伺服器仍會核對帳號、班級、開放名單、時間及活動開關。

- 學生預演：`annual-challenge.html?class=main&mode=rehearsal`。
- 學生正式闖關：`annual-challenge.html?class=main&mode=official`。
- 關主台：既有 Worker 的 `/admin/annual/annual-challenge.html?class=main&mode=rehearsal`，可在管理頁切換模式。

學生沿用原本完整六位學號及密碼，同分頁可沿用有效登入。學生頁固定使用入口網址所指定的模式，不會隨關主切換管理頁而進入另一模式。未開放或未獲允許時顯示說明及回首頁入口，不因此清除原平台的有效登入。每個學生畫面頂部都有「回池東探險島」；保存結果尚未確認時，先重試原操作再離開。

關主使用原本已授權的 Google 教師帳號，在自己的裝置選題、評量及簽章；登入一次即可連續操作，不必每題解鎖。孩子使用自己的 iPad，聲調關亦可使用教室大屏。活動管理老師仍可設定活動；一般關主登入後直接進入「關主桌」，依伺服器授權選擇可操作的關卡及預演／正式模式。本次指定的一般關主可操作全部五站，但不會出現活動設定、開放對象或重置預演按鈕，伺服器也拒絕這些管理操作。授權依老師提供的 Google 電子郵件與關卡設定，不需要密碼；授權名單不放在公開前端或本文件。兩小時期限、登出或換人才重新登入。大屏聲調完成後可按「換下一位登入」。

## 五關流程與加題

五關可依現場順序進行，每關滿分20分，總分100分。每關目前題目都完成後，關主會看到「要再增加幾題嗎？」；可選每次加1至5題，或不加題、直接評分簽章。加題後必須完成新增題目才能簽章，已簽章的卡不能追加或覆寫。

| 關卡 | 選題與作答 | 開始題數、加題及評分 |
| --- | --- | --- |
| 聽音辨識 | 關主從21聲符、16韻符及22結合韻選10個不同符號；孩子聽老師讀，用愛的小手指黑板上的對應符號 | 通過2、提示後通過1、未通過0。可增加1至5個尚未考過的符號，最多59題；超過10題時每頁顯示10題。分數為 `四捨五入（逐題得分 ÷ 題數 ÷ 2 × 20）`，簽章總分依評量鎖定 |
| 先聲奪人 | 每題由關主從三個候選詞選一個，孩子聽音檔並選每個字原本的聲調 | 每位孩子開始時可選3至8題，預設4題；開始及追加題目都只選沒有變音的基本題。整關最多30題。錯字須訂正到正確，每字首次作答計分，整關換算20分 |
| 東拼西湊 | 關主從三個1至2字國字詞中選一個，傳給孩子；孩子可按「聽詞語」，以聲符、韻符、結合韻及聲調逐字拼出 | 每位孩子開始時可選3至8題，預設5題；每次可加1至5題，整關最多30題。沿用既有核定詞語錄音與注音答案。錯字須訂正到正確，每字首次作答計分，整關換算20分 |
| 照做不誤 | 每次由關主從三個短動作選一個；孩子看注音並做動作，關主記下表現 | 開始可選1至8題；動作不超過5個國字，每次可加1至5題，整關最多30題。由關主依整體表現評分 |
| 書聲琅琅 | 孩子點放大的九課幸運輪，拿課本朗讀抽中的課次 | 先抽一課；加題後從尚未抽過的課次中繼續抽，最多九課。已抽課次保留且不重複，不收錄課文；由關主評分 |

照做不誤的老師三選一、老師查看已選題及孩子作答畫面，都以每字直排注音顯示：聲符在上，後續符號依序往下；輕聲點放在整組注音的正上方，其他聲調固定在該字最下方符號的右上方，未標記的一聲維持不標。孩子畫面只顯示注音，不加國字答案。這項排版不改題庫內容或其他關卡。

先聲奪人目前不出變音題，沿老師核定答案選原本聲調。尚未作答的舊變音題改為基本題，若已選但尚未作答，會回到關主三選一；已作答與已簽章紀錄保留。題庫中「一／不」及變音規則不由新介面重新推算。聽音以明確的三個評量按鈕操作，保留綠／黃／紅光、圖示和分數，避免單擊／連擊誤判；尚未評量與0分分開。簽章前可更正或清除逐題評量，修改只取代該題結果，不累加點擊次數。

先聲奪人與東拼西湊第一次答錯後，會保留已填答案並標出需要訂正的字，顯示「再試一次，可以問問老師」。孩子須改到全部正確才能前往下一題、加題或簽章；重試不再扣分。每個字原始滿分2分，首次答錯該字扣2分，聲符、韻符、聲調即使同字多處有錯也只算一個錯字。整關分數為 `四捨五入（（全部已選題目的總字數 − 首次錯字數）÷ 總字數 × 20）`，追加題目一併計算，分數由系統鎖定後交關主簽章；例如共10字錯1字為18分。

舊版已簽章及整關已答完的紀錄保留。舊版進行中卡片已完成題目不要求重做，尚未作答題目採新版訂正流程；舊卡追加新題時採新版計分，能由原答案推算的首次錯字納入計算。

## 每關五枚印章與簽名

共25枚印章，每一關只顯示該關自己的五枚，不能跨關選章。

| 關卡 | 五枚印章 |
| --- | --- |
| 聽音辨識 | 貓頭鷹、小鹿、小象、無尾熊、海豚 |
| 先聲奪人 | 小白兔、小鳥、青蛙、企鵝、小雞 |
| 東拼西湊 | 小狐狸、小熊、浣熊、松鼠、水獺 |
| 照做不誤 | 小猴子、貓熊、小狗、倉鼠、袋鼠 |
| 書聲琅琅 | 小貓、烏龜、小獅子、刺蝟、羊駝 |

孩子完成目前題目、尚未簽章時，可以先選喜歡的印章。關主評分時預選孩子的選擇，仍可在同關五枚中確認最後印章。孩子選章不等於自行給分或蓋章，也不會清除關主正在寫的簽名。

簽章分兩步：先確認0至20分與印章，再手寫簽名；建議為選填，最多200字，另有分頁。來回切換步驟保留已寫簽名與建議。保存結果未知時鎖住原內容、保留原請求供重試，避免畫面修改後送出的卻是另一份簽章。完成後可查看印章、分數、簽名及老師的話，也可列印五關闖關卡。

## 預演與正式分別管理

活動管理老師的管理頁分為「關主桌」、「活動設定」、「開放對象」及「重置預演」。一般關主只有關主桌，可在各站間切換、選擇目前模式已允許的學生並完成評量。回到關主桌或切換模式時會重新讀取可用學生名單，不必登出再登入。上方模式切換只選擇目前查看、設定或操作的模式，不會自動開放另一模式。

預演及正式各有獨立的開關、指定學生名單／本班所有學生選項、開始與結束時間。開放對象每頁八人，可跨頁勾選；按「保存」後才生效。只儲存目前模式的設定，不將其名單或開關複製到另一模式。這次更新保留原有預演指定對象，正式維持關閉，需管理老師明確保存開放設定才啟用；不因日期推移或預演結束自動開正式。

學生卡依班級、年度、模式、預演輪次及完整學號各自保存。預演不計正式成績，切換不複製或清除兩邊卡片，也不發星星或寫普通學習成績。關主桌只列出目前模式允許的學生；設定頁透過獨立設定讀取，不必先找到可開啟闖關卡的學生。

「重置預演」在預演已開放時開始新一輪：孩子取得本輪空白卡，舊輪次及正式卡仍保留，不是刪除資料。重置不會開正式，也不會改動兩模式的開放名單。相同重試不會重複增加輪次；舊輪的遲到答案或簽章不能寫入新輪。

## 平板與連線

畫面以1024×768橫向及768×1024直向為目標，必要內容採分類、分頁或步驟切換：聽音三分類及十題一頁、拼音四分類及逐字切換、學生名單八人一頁、評分／簽名兩步、成果建議獨立頁。轉盤依可用畫面高度放大，列印另有完整樣式。新版是否通過各尺寸量測，以發布交接的瀏覽器驗收紀錄為準；學校實體Safari、觸控筆、軟鍵盤、Google登入視窗及Wi-Fi仍須現場確認。

已登入且正在關卡內、頁面可見、網路在線、活動開放及未保存中，才以每三秒前景同步接題。請求不重疊，失敗逐步延長至30秒。首頁只查詢該學生自己的兩種開放狀態。登入準備及驗證都有逾時提示；不能將桌面模擬描述為離線或跨iPad已驗收。

## 整合與保存契約

- `annual-challenge-stamps.js` 是25枚印章的共同索引，`stampsForStation`、`stampById`、`isStampForStation` 同時供前端及服務驗證使用。舊版已保存的跨關印章只保留唯讀顯示，新選章及新簽章一律限同關。
- 學生沿既有登入驗證呼叫 `/annual/api/{session,availability,card,command}`；關主沿既有Google驗證及班級授權，使用同來源 `/admin/annual/api/{session,roster,config-read,card,command,config,reset-rehearsal}`。學生端不取得全班名單、候選題、教師驗證資料或其他孩子的卡。
- 每個請求帶明確 `mode`。設定使用 `{year,patch:{revision,access,...}}`；`access.rehearsal` 和 `access.official` 各含 `enabled`、`allStudents`、`seats`、`startsAt`、`endsAt`。`config-read` 供教師讀取年度設定，一般關主的名單只含有效學生且不含教師授權文件；`session` 與 `roster` 對一般關主僅回兩模式允許的有效學生聯集。一般關主的角色保持 `teacher`，站點依 `stations` 驗證；只有 `organizer` 可寫 `config` 或 `reset-rehearsal`。學生 `availability` 僅回其本人兩模式的 `enabled/allowed`。
- 聲調及拼音 `start` 帶 `count:3..8`；`extend` 帶 `count:1..5`，聽音另帶同數量、未考過的 `symbols`。學生 `choose-stamp` 帶該關 `stamp`，只在目前題目全數完成且未簽章時接受。
- 新聲調／拼音卡使用 `answerPolicy:first-error-character-scaled-v1`。結果保留首次答案與錯字數、最新答案／錯字位置、作答次數；`completed:false` 表示仍待訂正，不是題目完成。學生只取得自己答案與錯字位置，沒有正確答案。讀卡僅投影相容狀態、不寫資料；有效命令才按版本原子保存，舊命令拒絕但原成功請求重送仍冪等。
- 命令核對卡片版本、活動狀態、預演輪次與 `requestId`，原子保存並處理重送。簽名使用有限的正規化座標，不接受任意SVG或檔案。沿用原D1持久保存，不把本機示範記錄混入正式學生資料。
- 本輪保留原學生登入、班級、普通題庫、音訊、星星及探險存檔。本輪年度頁及核心載入鏈快取標記為 `20261111-retry1`，未修改的登入及素材保留既有版本；新增靜態資產須同時提供給GitHub Pages學生頁與既有Worker關主頁。

## 本機試玩與發布驗證

本機示範使用虛構帳號及獨立保存區；「示範關主解鎖」只供本機同裝置交接，不是正式教師驗證。原多檔頁應經本機預覽服務開啟；直接開檔時，啟動程式會引導至更新後的單檔試玩。

`tools/build-annual-standalone.mjs` 只打包列明的模組、題庫、樣式及25枚印章；單檔產物位於工作區 `output/annual-challenge-20261103/注音闖關單檔試玩.html`。虛構進度只留在該瀏覽器；若禁止儲存，仍可使用本頁記憶體試玩。詞語音訊沿原工作區檔案位置，檔案搬移或瀏覽器阻擋音訊時由關主朗讀。這不代表單檔可取代學校兩台iPad的正式連線流程。

發布後使用本機 `output/annual-challenge-20261106/verify-published-frontend.mjs --commit=<本輪完整提交SHA>`，比對公開前端的年度程式、25枚印章、共同索引、入口及重要既有平台檔。文字先統一CRLF再比SHA-256，圖片／音訊逐位元核對；既有檔另外對照更新前基準。腳本只讀公開靜態檔，不登入、不呼叫學生API或寫入學生資料。這項檔案一致性檢查不能代替雙模式授權、保存重試、平板畫面或實體iPad驗收。
