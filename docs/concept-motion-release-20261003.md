# 新反派戰鬥動作預覽 · 2026-10-03

本次完成其餘 31 位新反派的動作，沿用已確認的銀狼侯製作方式。加入既有銀狼侯後，統一預覽共有 32 位角色、384 個姿勢。每位新角色都有六個攻擊關鍵姿勢，以及防禦、受擊、恢復、個別勝利、捧星星和敗北姿勢。

造型依原先卡面保留。人形使用自己的杖、扇、槍或魔法；幻獸依爪、蹄、角、翅膀和蛛足出招；茶壺、樂盒、寶箱等維持物件造型。勝利動作依角色區分。捧星星只在切換成收藏後我方時開放，我方在右側向左攻擊，敵方在左側向右攻擊。

這次只發布動作預覽，不新增正式遭遇、不更動角色所有權與學生資料。正式遊戲維持隨機遇敵，同一反派累積全對擊敗三次才能收藏。造型圖鑑新增全部動作入口與每位角色的個別入口。

預覽具有正常、半速、四分之一速度、暫停、時間軸與逐姿勢查看。依使用者減少動態設定預設暫停動作；只載入選定角色的兩張透明圖集，保留最近三位的快取。

素材使用內建 imagegen、原造型參考與透明背景生成。原始 PNG 保存在 assets/battle-sprites/concepts-20261003；上架使用 62 張 WebP。四張較擁擠的圖集已重製為 v2，原版仍保留。完整提示詞與來源紀錄見同目錄的 concept-monster-animation-prompts-20261003.json 與 concept-monster-animation-sources-20261003.json。
