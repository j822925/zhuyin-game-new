# 新反派的不同關卡收藏規則

版本：20261004-levels1。新上架的 32 位反派必須在聽音、拼音、朗讀三個關卡，各遭遇同一位反派並完成一次整回合全對，才能收藏及選為我方角色。同關重複全對只保留該關完成標記。`single` 與 `compound` 都屬聽音；小考及連線對戰依其實際聽音／拼音內容計入，不算新關卡。原有四位反派維持累積三次整回合全對。

每次新回合仍從 36 位反派中隨機抽取；孩子不能自行挑選敵人。未全對、不完整回合、儲存失敗不增加完成標記；重送同回合沿用確認過的收據，不重複累計。收藏與角色選用由伺服器判定，正式遊戲、朗讀、考試、連線及試玩採用相同學習關卡分類。

## 現有紀錄

已收藏的反派保留，不追回角色。以雲端原有完整全對的練習、已清除紀錄的獎勵收據、小考收據回填可查證的不同關卡；不將僅有累計次數的舊資料推測成不同關卡。進度持久保存在 `monster_card_ownership.level_mask`，後續清除答題紀錄不清除收藏進度。`monster_encounters.level` 綁定新版回合的學習關卡，舊版已開始的回合仍可按其經驗證的實際關卡完成。

## 未來聲調關卡

共享規則預留聲調（第 4 個標記），現在 `MONSTER_TONE_COLLECTION=false`，不要求尚未完成改版的聲調關卡。聲調正式完成後需另行接上其完整回合驗證及怪物遭遇，再開啟此設定；此後未收藏的反派須四關皆完成。既有收藏依本次保留規則不被撤銷。伺服器透過 `monsterRequiredLevels` 向收藏、戰鬥與獎勵畫面傳遞目前需求。

## 部署與檢查

前端獨立副本：`.local/collection-release-20261004`。後端：`.local/monster-levels-production-20261004`。以最新 `.local/rewards-production-20261004/production.js.map` 為基礎，保留星星規則及教師後台；只改 monster-cards、worker 的收藏入口、exams、online-settlement，新增共享關卡規則。`audit.json` 核對其他模組不變。後台 public 目錄保留最新星星餘額與勾選工具。

資料庫採新增欄位的 `0014_monster_levels.sql`，兩個班級都包含，雲端執行並寫入 `d1_migrations`；不套用工作區其他未上架的遷移，不本機匯出學生資料。部署後再以 OR 合併回填舊收據，涵蓋版本切換期間仍由舊版完成的回合。

驗證：36 位反派、兩個班級共 608 次虛構練習；同關重複、結合韻、錯題、跨關收藏、角色選用、重送、班級隔離、交易回滾、舊收藏保留、未來四關條件；另完成實際考試與跨班連線結算的關卡分類測試。試玩畫面核對 32 組關卡標記、重複關卡提示及 390px 無溢出；朗讀核對儲存失敗及確認重試後才發收藏、三種寬度和既有角色動畫。正式網頁驗證使用虛構隔離資料與攔截 API，不傳送學生答題紀錄。
