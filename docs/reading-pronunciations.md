# 同音字朗讀判斷

2026-10-01，前端版本 `20261001-retry1`，畫面標記 `cloud6`。老師要求同音及相似讀音皆可通過，改為寬鬆練習。

第四關對所有題目使用完整字詞讀音比對。既有題目、繁簡字形及已審核的同音寫法先比對；其餘漢字查詢字音索引。忽略所有聲調及輕聲差異，例如「梨子／離子」「木馬／木麻」。音節數與次序必須相同；每個音節除完全相同外，允許一處指定近音替換：聲母 ㄓ↔ㄗ、ㄔ↔ㄘ、ㄕ↔ㄙ、ㄋ↔ㄌ，或韻尾 ㄣ↔ㄥ、ㄢ↔ㄤ。同一音節不允許兩處替換，也不接受任意編輯距離、漏字、多字或部分字串。這是一項明確的遊戲寬鬆規則，不表示以上不同讀音在語言上完全相同。答對畫面仍呈現原題繁體詞語；不把題目答案送給語音辨識服務。

完整詞語的字典讀音優先，避免把「銀行」中的「行」任選成「行走」的音。未收錄的整詞依最長已知詞切分，再查單字；各段的候選讀音在寬鬆規則下皆相符才通過。僅聲調不同的候選不再視為未解決的多音字。有未解決的多音字或未知字時不計分，保留原題重錄。字典無法涵蓋所有罕見字、名字與新詞，不能保證所有辨識結果都能判讀。既有特別審核的同音詞仍保留。

這是辨識文字的讀音核對，不是直接聲學評分；若辨識服務本身把錯音改寫成正確文字，仍可能通過。沒有新增付費服務、外部查字請求或錄音保存。

## 重錄練習模式（2026-10-01）

老師明確選擇：所有不相符或無法確認的辨識結果保留原題重錄，不扣分、不新增成績列、不推進角色戰鬥，也不把原始錯誤文字當作孩子說過的內容顯示。只有完整符合原有寬鬆讀音規則才記錄通過；不以包含答案的子字串判定，也不把「拉茲／蠟燭」「雞雞／企鵝」新增為同音詞。五題均通過可獲三顆星；這是可重試的完成紀錄，不是第一次朗讀的正確率。沿用既有成績欄位 firstCorrect 表示本題已通過，歷史成績不修改。

雲端移除 initial_prompt 中的繁體中文指示，避免把提示當作音訊內容續寫；仍指定中文轉錄及 condition_on_previous_text=false，保留繁簡字形比對。提示干擾是依回報內容與參數用途推測，沒有原始錄音可確認；不宣稱這能消除模型誤聽或保證兒童準確率。不新增自動重送，免費額度控制不變。

## 資料來源與重建

來源為中華民國教育部《國語辭典簡編本》`dict_concised_2014_20260626`，沿用題庫的本地參考資料。只抽取字詞和讀音事實，不收錄或改写釋義、例句、圖片、錄音。原始注音的輕聲位置統一為音節末端，字音以可逆索引編碼。來源檔 SHA-256：`37cf634bbc20d0ec26e87a46c4b87c66f8127561748cc924a28dbe86db3b4911`。

索引包含 44,656 筆合格的一至四字原始讀音記錄、87,936 種繁簡及混合字形，其中 7,916 種單字字形、1,256 種帶聲調音節；43 筆特殊注音格式未自動採用。繁簡字形使用 opencc-js 1.4.2 / opencc-data 產生，授權見 `licenses/opencc-js-MIT.txt`、`licenses/opencc-data-NOTICE.md`。此索引是判斷參考資料，遊戲題庫仍為原有 1,237 題。
