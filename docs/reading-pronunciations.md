# 同音字朗讀判斷

2026-10-01，前端版本 `20261001-graded1`，畫面標記 `cloud7`。老師要求同音及相似讀音皆可通過，改為寬鬆練習。

第四關對所有題目使用完整字詞讀音比對。既有題目、繁簡字形及已審核的同音寫法先比對；其餘漢字查詢字音索引。忽略所有聲調及輕聲差異，例如「梨子／離子」「木馬／木麻」。音節數與次序必須相同；每個音節除完全相同外，允許一處指定近音替換：聲母 ㄓ↔ㄗ、ㄔ↔ㄘ、ㄕ↔ㄙ、ㄋ↔ㄌ，或韻尾 ㄣ↔ㄥ、ㄢ↔ㄤ。同一音節不允許兩處替換，也不接受任意編輯距離、漏字、多字或部分字串。這是一項明確的遊戲寬鬆規則，不表示以上不同讀音在語言上完全相同。答對畫面仍呈現原題繁體詞語；不把題目答案送給語音辨識服務。

完整詞語的字典讀音優先，避免把「銀行」中的「行」任選成「行走」的音。未收錄的整詞依最長已知詞切分，再查單字；各段的候選讀音在寬鬆規則下皆相符才通過。僅聲調不同的候選不再視為未解決的多音字。有未解決的多音字或未知字時不計分，保留原題重錄。字典無法涵蓋所有罕見字、名字與新詞，不能保證所有辨識結果都能判讀。既有特別審核的同音詞仍保留。

這是辨識文字的讀音核對，不是直接聲學評分；若辨識服務本身把錯音改寫成正確文字，仍可能通過。沒有新增付費服務、外部查字請求或錄音保存。

## 答錯與無法確認的區分（2026-10-01）

cloud6 將全部不相符結果改成重錄後，老師回報故意把早安念成晚安卻未判錯。cloud7 恢復明確不同詞語的錯題計分：先執行既有同音／近音比對，通過者維持通過；若讀音不同，且完整辨識文字是 1,237 題詞庫內的正式詞語（含繁簡字形），記錄一次錯題並開放下一題。例如早安→晚安、蘋果→香蕉會判錯。已知字詞的多音讀法若仍無法確認，維持重錄。

不在題庫的不同文字、未知字、羅馬拼音、附加字幕等仍保留原題重錄，不新增分數列或戰鬥進度，也不自動通過。這個保守界線不是聲學信心判斷；題庫外的明確錯詞可能仍被要求重錄，而模型若誤聽為另一個題庫詞也可能造成誤判。不能宣稱系統能分辨所有真實念錯與辨識錯誤。

五題首次可判定結果全對得三顆星，三至四題得一顆星；無法確認的重錄不計為首次有效結果。firstCorrect 保持為首次可判定的結果；不修改 cloud6 或更早已保存紀錄。題目不送給模型；不以包含答案的子字串通過。

雲端仍沿用 cloud6 已移除 initial_prompt 的中文轉錄設定及 condition_on_previous_text=false。免費額度、不保存錄音、無自動重送均不變。本次只修改計分與說明，沒有更換語音模型，也未驗證真實兒童語音準確率。
