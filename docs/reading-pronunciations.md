# 同音字朗讀判斷

2026-09-30，前端版本 `20260930-sound1`，畫面標記 `cloud4`。

第四關對所有題目使用完整字詞讀音比對。既有題目、繁簡字形及已審核的同音寫法先比對；其餘漢字查詢字音索引，音節數、順序、聲母、韻母、聲調（含輕聲）必須相同。答對畫面仍呈現原題繁體詞語。不用模糊相似度、部分字串或去聲調比對，也不把題目答案送給語音辨識服務。

完整詞語的字典讀音優先，避免把「銀行」中的「行」任選成「行走」的音。未收錄的整詞依最長已知詞切分，再查單字；各段均有唯一而相符的讀音才通過。有未解決的多音字或未知字時不計分，保留原題重錄。字典無法涵蓋所有罕見字、名字與新詞，不能保證所有辨識結果都能判讀。既有特別審核的同音詞仍保留。

這是辨識文字的讀音核對，不是直接聲學評分；若辨識服務本身把錯音改寫成正確文字，仍可能通過。沒有新增付費服務、外部查字請求或錄音保存。

## 資料來源與重建

來源為中華民國教育部《國語辭典簡編本》`dict_concised_2014_20260626`，沿用題庫的本地參考資料。只抽取字詞和讀音事實，不收錄或改写釋義、例句、圖片、錄音。原始注音的輕聲位置統一為音節末端，字音以可逆索引編碼。來源檔 SHA-256：`37cf634bbc20d0ec26e87a46c4b87c66f8127561748cc924a28dbe86db3b4911`。

索引包含 44,656 筆合格的一至四字原始讀音記錄、87,936 種繁簡及混合字形，其中 7,916 種單字字形、1,256 種帶聲調音節；43 筆特殊注音格式未自動採用。繁簡字形使用 opencc-js 1.4.2 / opencc-data 產生，授權見 `licenses/opencc-js-MIT.txt`、`licenses/opencc-data-NOTICE.md`。此索引是判斷參考資料，遊戲題庫仍為原有 1,237 題。

- [教育部官方資料與版本](https://language.moe.gov.tw/001/Upload/Files/site_content/M0001/respub/dict_concised_download.html)
- [教育部原始公眾授權使用說明](https://language.moe.gov.tw/001/Upload/Files/site_content/M0001/respub/conciseddict_10312.pdf)
- [原始資料 CC BY-ND 3.0 TW 條款](https://creativecommons.org/licenses/by-nd/3.0/tw/)

教育部不為本遊戲或自訂判斷方式背書。延續 `reading-wordbank-sources.md` 的字音事實用途與來源標示。

重建：`node tools/build-reading-pronunciations.mjs /path/to/dictionary-rows.json /path/to/opencc-js/dist/esm/full.js`，產出 `reading-pronunciation-data.js`。工具程式只讀取 A（字詞）和 G（注音）欄。字典更新需同步檢查多音詞及同音、不同聲調的回歸案例。

驗證：40 項測試涵蓋所有索引讀音的解碼一致性、新增整詞及逐字同音、繁簡混合、音節次序、不同聲調、輕聲、多音詞、未知字、不完整或過長答案，以及原有錄音、額度、注音篩題。另以獨立模擬錄音與帳號檢查五題同音答案及三顆星；未使用真實學生資料。
