## 手寫判定

- 模仿：左邊範例、右邊空白，兩個同尺寸田字格。核對字形、筆畫數、順序與方向。
- 整字中心在 X、Y 軸各容許偏移格子寬度的 8%；等比例大小容許 ±15%。另核對筆畫相對位置，不會逐筆各自移位後放行。
- 這是初始工程設定，不是教育部標準或已完成兒童筆跡校準的門檻。須依實際手指／觸控筆測試調整。
- 非模仿：沿原 automatic-v1，整字平移與縮放後仍可辨認正確；仍核對字形、筆畫、方向、順序。不是任意塗寫都能通過。
- 錯字保留第一次筆跡，播放筆順後再寫；中斷的筆跡先重寫，不直接當成錯字。

## 共用入口與資料

- 國字營地增加三種練習。老師試玩使用虛構範例與試玩星星。

- 老師在已教範圍的姓名練習分頁管理本班姓名及逐字注音。沿原教師登入與班級權限。
- 名冊只存私有資料庫，學生只能讀自己的題目。公開檔僅含通用字形，不能含姓名與學號對照。
- 新 API：學生 /hanzi/copy/*；老師 /admin/api/hanzi/copy/*。新增 0033_hanzi_copy_name.sql，須先遷移再部署。
