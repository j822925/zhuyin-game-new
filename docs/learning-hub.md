- 學生：學習廣場的每日任務、老師小考、我的錯題本。關卡只負責作答，沒有獨立背包或教師管理入口。
- 老師：每日任務派回合；老師小考建立／查詢所有關卡小考；當月錯題查各關錯題、紀錄與國字筆跡；已教範圍管理國字課次、學期與生字。
- 舊作業不刪除：仍在有效期間且指定給該生的作業列在每日任務；後台每日任務保留舊作業調整／停止，新作業只從共用任務設定建立。

## 新增關卡必接的介面

新增關卡時，直接擴充既有後台，不另做一套管理選單或作業頁。

1. 在後端 task-plan.js 的 LEVELS 登記名稱／模式，實作可信完成紀錄，接 activityCounts 與 matchesTask。每日任務進度只能由伺服器已保存的正式練習計算。
2. 學生 /learning/daily 經原學生 session 與班級隔離，只回傳該生的計畫／進度。daily.js 的 launch 指向既有關卡，結束回每日任務。小考、對戰不抵任務；新國字及數學單題錯題複習不抵一整回合。
3. 小考註冊原 exam-mode、共用 exam-list-section；學生只在 exam.html 列小考，不能混入指定練習。沿用 snapshot、重送去重與教師授權。
4. 錯題接 notebook.html 共用分類及 student-errors 的當月分類。不可把 API 載入失敗顯示為全部畢業；朗讀保留原 Safari 跳轉。
5. 班級切換與登出必須清掉名單／表單／逐題資料，非同步請求須檢查當前身分與版次。
