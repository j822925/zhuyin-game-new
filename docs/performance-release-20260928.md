# 載入優化（2026-09-28）

在目前正式版加入已於教師試玩區驗證的素材優化。原網址、主畫面圖示、帳號、班級資料、題庫音檔及獎勵規則維持不變。

- 69 張主要圖片由合計 120,423,135 bytes 縮為 9,241,768 bytes，另有 66 張小縮圖（1,091,824 bytes）。這是整批素材，不是每次開場下載量。
- 開場只準備五個核心素材；等待時依注音順序輪播已上架的 18 張星使卡片。已快取不強迫等待；可先進遊戲。
- 課前準備：最多 400 個已教範圍素材、同時最多兩個下載，已下載部分可沿用。建議平板分批準備。
- 公開圖片與音檔暫存：上限 512 筆／96 MiB、單檔 4 MiB、30 天。登入、成績和私人 API 不暫存。儲存空間不足不阻止遊戲開啟。
- 題目後預載接下來兩題；頭貼採小圖、隱藏收藏不一次下載全部大圖。正式角色目錄和原始圖片保留，僅顯示時選用輕量版本。

登入、交卷和連線對戰仍需要網路；瀏覽器或 iPadOS 可能清理暫存。本次不是完全離線版，亦未宣稱已完成全班實體 iPad 同時壓力測試。

回歸測試：優化前基準 131 項／126 通過／5 既有失敗；初次優化後 136 項／131 通過／相同 5 項既有失敗。另增素材與正式設定保留測試。既有失敗涉及過時音檔與版本斷言，不在本次修改音檔範圍內。
