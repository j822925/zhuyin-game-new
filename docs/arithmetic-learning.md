# 加減玩 ARITHMETIC-POLISH-v2

更新：2026-11-15。前端基準 d658a371；發布狀態以專案協作/交接/arithmetic-learning.md與線上驗證為準。

## 學生操作

- 學習廣場使用既有兔子素材作為加減玩入口；關卡內只保留大標題與設定，不放背包、教師連結或副標語。
- 10、18、99、999、9999五種範圍全部可選；加法／減法／混合、進退位／不進退位／綜合、5／10／20題。含0，不出負數，題目不重複；範圍不足時提示調整題數。
- 敵方在左、我方在右，放大角色及設定標題。上方返回有明顯箭頭；使用既有戰鬥引擎，每題第一次作答才觸發一次攻擊／受擊。
- 小考及練習作業從既有「老師小考」選取；錯題整合至既有「我的錯題本」，可看全部或只看加減玩。完成後返回來源入口。
- 練習可用提示；99以上有直式及手寫草稿，不上傳筆跡。小考禁止提示與重答。

## 星星與資料

- 本版開始的練習回合，所有題目第一次都答對，整回獲得1顆正式共用wallet星星，無每日上限。提示不額外扣除資格；訂正不改第一次成績，小考不套用練習獎勵，舊回合不補發。
- 成績與星星在同一D1原子交易提交。重送、並行提交只入帳一次；錢包寫入失敗時成績也回滾，可安全重試。按班級及完整學號隔離。
- 前端sessionStorage只保存本分頁未完成計算回合；原平台登入session另獨立保存，不保存PIN。回合資料不逐題上傳或輪詢。
- 錯題本沿最近300回合、同算式最新紀錄；獨立首次答對後移出，歷史成績保留。

## 教師後台

- 沿既有「老師小考」建立加減玩小考或練習作業、指定學生與時間、查看成績、暫停及重新開放。
- 移除獨立加減法導覽及平常開放範圍控制。學生自行選五範圍、運算與進退位；教師建立小考的試卷設定仍固定。
- 紀錄及首次錯題整合至既有「當月錯題」，沿原月份、學生與來源篩選。可展開逐題首次答案、提示及訂正、查看星星。單次最多5000回合，超過時明確提示縮小日期。
- 舊數學作業／小考與紀錄保留；一般注音、聲調、朗讀、國字等原有流程不變。

## 驗證

20項測試涵蓋出題矩陣、0、首次／訂正、門禁、跨班隔離、試卷快照、重送、SQLite原子入帳／失敗回滾、15次全對無日上限、原老師小考／錯題本、教師建小考及月紀錄、登出再登入，以及兩個關卡共存與入口登出保護。Chrome模擬1024／768／390尺寸無橫向溢出，平板按鈕可見；已檢視畫面。
