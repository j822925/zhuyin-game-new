# 加減法挑戰 ARITHMETIC-v1

製作日期：2026-11-15。前端基準 dd77ca2；發布狀態以專案協作/交接/arithmetic-learning.md及發布驗證為準。

## 教學與操作

- 主畫面「加減法挑戰」→數字探險谷。10、18、99以內預設可選，教師亦能開放999及9999；所有運算數與答案介於0及範圍上限。含0，不出負數。
- 加法／減法／混合，不進退位／進退位／綜合；5／10／20題。教師作業另可指定多位數加減一位數或同位數。
- 出題不重複、加減混合數量差不超過1；兼容的題型約20%包含0／結果0。大數範圍優先包含相應位數。若符合範圍的題目少於題數，明確回覆需減少題數，不暗中重複出題。
- 大數字鍵盤及實體數字鍵／Enter，既有角色與怪物戰鬥。每題第一次作答才觸發一次攻擊／受擊，訂正不重扣血、不重算首次成績。
- 練習可看圓點、湊十／退到十提示；99以上有直式對齊及手寫草稿。手寫草稿不送出、不做辨識、切題清除。小考禁用提示與重答。
- 首次正確率、獨立答對、提示、訂正分開顯示與保存。本輪試用只保存數學成績，不發正式星星或卡片；未新增貨幣、未變更其他關卡獎勵或每日任務。

## 權限及後台

- 使用者直接授權限定兩個指定帳號正式上架測試。試用名單放私密Worker變數ARITHMETIC_PILOT_ACCESS，公開前端不包含名單。
- 首頁登入後只做一次可用性查詢。所有學生API每次仍重新驗證正式session、班級及試用名單；直連、偽造學號、跨班同號、登出、停用帳號不能繞過。教師沿原Firebase及班級授權。
- 現有後台新增「加減法學習」，含班級與個別學生範圍、指定作業、小考、暫停／重新開放、最近300回合、逐題答案、題型統計及CSV。
- 作業固定建立時設定，每回抽新題；小考固定建立時題目，每生每考一份。已有作答不可改原卷設定，可停用。小考截止後不能交卷；已成功提交的重送仍回原結果。
- 錯題本取最近300回合的同算式最新紀錄；獨立首次答對後移出，原歷史分數不改。
