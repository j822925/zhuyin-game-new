# 反派動畫畫格比例修正（2026-10-03）

夜蛾姬的防禦畫格原始頭部比例比待機大，而播放器原先分別使用攻擊和反應圖集的整體高度計算大小。翅膀、衣襬、武器和彎腰又改變了輪廓，導致切换姿勢時角色會忽大忽小。逐畫格限制站位也會在衣襬展開時令角色橫向跳動。

本次為 32 位角色、384 個姿勢加入各自的頭部／身體核心比例資料。所有姿勢共用一個角色世界尺寸與一個整組安全縮放值，逐畫格只補償原稿的繪製比例差異；保留蹲下、彎腰、展翼和伸展武器造成的自然輪廓變化。整組畫格預先決定站位，避免逐畫格夾限位置。特效和地面陰影跟隨新的固定站位。

比例校準以原始透明畫格的局部特徵對照輔助，再檢視實際顯示尺寸的待機／防禦／恢復對照；遮擋、閉眼、轉頭或特徵辨識偏差的畫格人工修正。毒菇、雪豹、樂盒及細長角色均另外複核。未重新生成或修改原始角色圖。

驗證：32 位完整載入、384 個姿勢，兩側六種動作、十個時間点及減少動態模式共 7,680 個位置檢查，無角色裁切、非有限座標或逐畫格站位跳動。以夜蛾姬原始臉部膚色像素另行量測，修正後防禦臉部等效直徑是待機的 1.0071 倍，恢復為 0.9889 倍，均在 5% 容差內。完整預覽檢查通過，包括攻擊方向、我方限定捧星星、切換競態、速度／暫停／逐格、手機平板桌面版面、載圖失敗恢復及既有銀狼侯獨立預覽。

版本：`20261003-scale2`。僅更新概念動畫預覽與卡面預覽連結。新角色仍未接入正式練習遭遇、收藏或學生資料。
