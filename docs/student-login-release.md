# 學生登入引導與首頁保留登入 — 2026-09-20

## 行為

- 未登入點首頁的關卡、模式、頭貼、轉蛋、小考、收藏、設定、語音或首頁圖示，先顯示大座號按鈕，再輸入四位密碼。登入成功才接續原操作；取消不會進入功能。
- 原本的座號下拉選單仍可使用。新「換人登入」清除原學生與夥伴驗證，再讓下一位選座號。
- 上方品牌／首頁改為頁內回首頁，不重新載入；未完成回合會先確認是否離開。
- 正式關卡結束回首頁、同分頁重新整理、小考及收藏來回，均延續主學生登入。進小考只預選座號，仍須按「開始／接續」，不自動消耗正式作答機會。

## 登入安全

- 只把主學生的座號、伺服器到期時間、短期登入憑證放在 sessionStorage（同一分頁）；不保存 PIN，不放 URL，不使用 localStorage 保存登入。
- 遊戲路徑與試玩／正式模式分開。夥伴驗證留在當頁記憶體，不取代主學生，也不跨頁保留。
- 不延長後台原本兩小時期限。到期、重設密碼、伺服器拒絕時清除該憑證，仍須重新驗證；權限仍由後台判定。
- 返回快取頁會重新同步頁面，避免換人後瀏覽器上一頁復活旧登入。
- 若瀏覽器禁止 sessionStorage，退回當頁記憶體登入；當頁首頁仍保持登入，跨頁則需重新驗證。
- 共用裝置交给下一位前應使用「換人登入」。瀏覽器分頁還原／複製可能沿用該分頁工作階段，不能把關閉分頁視為伺服器撤銷。

## 驗證

- 192 個自動測試通過，包含新增加的工作階段到期、清除、儲存故障、PIN 排除與模式隔離測試。
- 隔離 Chrome、拋棄式本機 D1、虛擬 01／02 號測試；沒有讀寫正式學生紀錄。
- 點測 13 個首頁入口；手機登入視窗無橫向溢位。
- 完成 10 題普通回合後，上方首頁不載入新文件、不重問密碼；未完成回合有離開確認。
- 重新整理、小考和收藏回首頁仍為原學生；僅開小考頁不建立作答。
- 測試錯密碼、取消 PIN、換人、雙人夥伴、無 opener 新分頁、到期與老師重設密碼後重新驗證。
