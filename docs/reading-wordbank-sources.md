# 朗讀詞語題庫

2026-09-28：1,237 個兩到四字詞語（新增 1,207 個，保留原有 30 題的題號與注音）。分類包含家庭、身體、學校、飲食、水果、動物、自然、家居、交通、遊戲運動、動作禮貌、顏色時間、心情及四字詞。

新增詞語由人工整理的生活詞語候選清單篩選，注音參考中華民國教育部《國語辭典簡編本》，資料版本 dict_concised_2014_20260626。只使用字詞及讀音事實，未收錄釋義、例句、圖片或錄音。輕聲位置由詞首標記正規化為遊戲內的音節尾端標記；顯示時仍放在注音上方。相同字詞的不同讀法依生活語義挑選，例如「肚子」選腹部、「睡覺」選睡眠、「便當」選食物。

詞語與讀音的參考來源為教育部，不表示教育部對本遊戲或出題方式背書。詞語難度涵蓋日常詞到進階四字詞，並非所有詞語都適合剛學注音的孩子。第四關目前尚未依老師勾選的注音篩題。

每回合保留兩題兩字詞、兩題三字詞、一題四字詞，同一回合題號不重複；五題全對三顆星、三到四題一顆星。相同注音與聲調的已收錄整詞書寫（例如姐姐／姊姊）皆接受，避免辨識文字選字不同而誤判；不採模糊或部分比對。

資料维护：data/reading-candidates.txt 是選詞清單，tools/build-reading-wordbank.py 產生 reading-words.js。新題號使用穩定的 moe-字詞號，既有題號不可重新編號。前後端均使用 reading-core.js；發布時先更新後端驗證，再更新前端，防止新題成績被舊後端拒收。
