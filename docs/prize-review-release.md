# 星光開蛋、角色陪伴、小考答錯複習（2026-09-19）

## 顯示與獎勵

- 小考滿分資格顯示大型金色星光蛋；點擊後搖晃、流星、放大角色、星光，再回完整卡片。未取得卡片仍不載入原圖。
- 一般轉蛋共用揭曉畫面；正常扣 5 星、重複得糖果規則不變。滿分星使不扣星，每場仍只能領一次。
- 圖像效果用 CSS/SVG，不新增影音資源、動畫套件或同時播放的音訊。減少動態效果設定下不搖晃、縮放或放流星。
- 一般關卡、輪流模式及小考在寬畫面右側顯示大角色和姓名；手機改成上方陪伴，避免遮住選項。未加入戰鬥／攻擊功能。

## 轉蛋卡住的程式原因與修正

- 舊前端即使 Cloudflare POST 已回覆保存成功，仍依序等交易查詢及所有參與者的錢包更新，才顯示獎品；各請求最長可等 45 秒。動畫只搖 3 秒，之後按鈕仍鎖住，容易像卡住。
- 新版直接使用已保存的 POST 結果；遺失回覆才查原交易。等待上限為 POST 12 秒、補查 5 秒；錢包更新最多 5 秒且不阻擋揭曉。
- 待確認交易保留原 ID；剩餘不足五顆星（包括零星）也能恢復上次開蛋。查詢明確攜帶原座號。連點有鎖、伺服器仍去重，無新增隨機抽取或重扣。
- 以上是從程式與隔離故障測試確認的缺陷；不是學校歷史網路紀錄分析，也不能保證實體 iPad 或校園網路永不斷線。

## 小考複習

- 新版作答送出 reviewEnabled；錯題保存 reviewed:false，回應只提供剛答過的正確文字及題音，暫不提供下一題。
- 前端等待音檔實際 ended 事件兩次才確認複習，不能按下一題跳過。被 iPad 自動播放限制或音檔失敗阻擋時，保留完成次數並提供喇叭重試；未播完不算一次。
- 重新整理／斷線／跨裝置恢復仍由後台返回未完成複習；改送下一題會被拒絕。音訊是否真的被人聽到無法由瀏覽器驗證，複習確認仍由客戶端送出。
- 原始答案、首次正誤、錯題統計、星星及單次考試規則不變。末題錯誤和到期後可完成複習，不會重複發星或新增作答。
- 相容已開啟的舊版頁面；需重新整理正式遊戲才能使用新的答錯複習。舊題目不追溯強制複習。老師後台試考仍是原本的預覽流程。
- 不新增資料表／不修改正式學生資料；利用既有答案 JSON 保存複習狀態。

## 驗證

- 184 項自動測試通過。
- 隔離 Chromium + 記憶體 D1：滿分蛋、連點只抽一次、放大後完整卡片、錢包卡住不阻止揭曉、回覆遺失後零星恢復同一筆、390px 排版及 reduced-motion。
- 實際小考前後端隔離流程：答錯後兩次 ended 之前不前進；重新整理保留複習；自動播放拒絕後手動恢復。手機、1100px 截圖人工檢查。
- 原角色設定、暱稱／原姓名分離、單人／輪流身份與答題鎖定瀏覽器回歸通過。音訊事件使用模擬，未宣稱在實體學校 iPad 完成聲音實測。
